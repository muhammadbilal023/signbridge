# SignBridge - full project
```
SignBridge/
  backend/    FastAPI server (see backend/README.md)
  Frontend/   Flutter app (see Frontend/README.md)
  start-dev.bat   opens both (Windows)
```
Quick start: read Frontend/README.md (it explains the Flutter files and Firebase) and backend/README.md (Python setup).
The trained sign-recognition model is NOT included: the backend runs in demo mode until you add models/word_model.onnx + labels.json.
